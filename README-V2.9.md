# JBE Academy V2.9 — Math Launch & Control

Implemented:
- Math-only public launch.
- Arabic Mathematics content (`MATH_AR`) separated from English Math content (`MATH_EN`).
- All other subjects retained internally but hidden publicly.
- Owner controls homepage teacher visibility and order.
- Owner controls program public/featured/status without destructive deletion.
- Teacher invite links can be generated without entering an email first.
- Unified portal entry for Student / Parent / Teacher / Administration.
- Delivery offerings support Online, Student Location, Teacher Location; Private/Group; Single/Package.
- Learning database foundation for Math skills, mastery, learning plans, lesson reports, homework progress and parent reports.

Deployment:
1. Run `jbe_academy_v2_9_math_launch.sql`.
2. Run `JBE_V2_9_PREFLIGHT_READ_ONLY.sql`.
3. Send the Preflight result for review.
4. Upload the site ZIP only after PASS.
